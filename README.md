# FF VPN config

Готовая ссылка для Clash Verge Rev / Mihomo:

```text
https://raw.githubusercontent.com/zTOFFOTz/vpn-sub/main/full.yaml
```

Как добавить:

1. Открой Clash Verge Rev.
2. Зайди в `Profiles`.
3. Нажми `New` / `+`.
4. Выбери `URL`.
5. Вставь ссылку выше.
6. Нажми `Save`, потом `Update`.

Как обновлять у всех:

- Я или ты меняем файл `full.yaml` в этом репозитории.
- У друзей в Clash Verge надо просто нажать `Update` у профиля.
- Ссылка остаётся той же самой.

Что внутри:

- новые VLESS-серверы от 15.06.2026;
- правила для Steam и Dota 2;
- старые правила для Roblox, ChatGPT/OpenAI, Discord, YouTube/Google, Telegram, GitHub, Cloudflare, Epic Games, Ollama, NVIDIA, HuggingFace и LM Studio;
- `DOTA-GAME` и `STEAM-CDN` по умолчанию идут с `DIRECT` первым, чтобы не портить пинг и загрузки, но их можно переключить на `AUTO-BEST`.
